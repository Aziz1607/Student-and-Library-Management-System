# CORBA (Java IDL) Project - Student & Library Management System

A distributed client-server application built with **CORBA** (Common Object Request Broker Architecture) and **Java IDL**.
This system enables remote management of student records, weighted grade calculation across examinations, and book borrowing operations from a university library.

## 🏛️ Architecture & Overview

The application follows the classic CORBA distributed architecture:
- **IDL Specification (`Institue.idl`)**: Defines data transfer structures (`Epreuve`, `Livre`) and remote object interfaces (`Etudiant`, `Promotion`).
- **Naming Service (`tnameserv`)**: Used by the server to publish the `Promotion` remote reference and by clients to resolve it dynamically (running on port `900` by default).
- **Server (`serveur/`)**: Implements POA servants (`PromotionImpl`, `EtudiantImpl`), manages student states and book loans, and exposes references via the RootPOA.
- **Client (`client/`)**: Provides an interactive, crash-proof command-line interface (CLI) to invoke remote operations on the server.

## ⚠️ Important Prerequisites (Java 8)

> **Crucial Notice**: The CORBA module (`org.omg.CORBA.*`, `idlj`, `tnameserv`) was deprecated in Java 9 and **completely removed from standard JDKs starting with Java 11**.  
> This project requires **Java 8 (JDK 1.8)** to compile and run.

If multiple Java versions are installed on your machine, configure your `JAVA_HOME` environment variable to point to JDK 8:
```powershell
# Example in PowerShell:
$env:JAVA_HOME = "C:\Program Files\Java\jdk1.8.0_202"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
```
*(The provided `.bat` scripts will automatically detect your local JDK 1.8 installation if present in standard directories).*

## 🚀 Build and Execution Guide

### Option A: Using Automation Scripts (Recommended on Windows)

1. **Compile the project**:
   ```cmd
   .\compile.bat
   ```

2. **Start the CORBA Server** (in a first terminal):
   ```cmd
   .\run-serveur.bat
   ```

3. **Launch the Client** (in a second terminal):
   ```cmd
   .\run-client.bat
   ```

---

### Option B: Manual Commands (JDK 8 required)

1. **Generate Java files from IDL (if modifying `Institue.idl`)**:
   ```cmd
   idlj -fall Institue.idl
   ```

2. **Compile all Java source files**:
   ```cmd
   javac -encoding UTF-8 Institue\*.java serveur\*.java client\*.java
   ```

3. **Start the Server**:
   ```cmd
   java -cp . serveur.Serveur
   ```

4. **Run the Client**:
   ```cmd
   java -cp . client.Client
   ```

*(By default, the CORBA Naming Service listens on port **900**).*
